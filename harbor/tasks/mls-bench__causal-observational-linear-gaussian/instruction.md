# Causal Discovery from Linear Gaussian Observations (CPDAG Recovery)

## Research Question
Implement a causal discovery algorithm that recovers the **CPDAG** from purely
observational data generated by a linear Gaussian structural equation model
(SEM).

## Background
Under linear Gaussian assumptions, observational data generally identifies
only the Markov Equivalence Class (MEC) of the true DAG, not a unique fully
directed DAG. The MEC is represented by a CPDAG. The method should be robust
across sparse and denser graphs and across noise levels, and should not rely
on dataset-specific constants.

## Task
Implement `run_causal_discovery(X)` in `bench/custom_algorithm.py`. It must
return a `causallearn.graph.GeneralGraph.GeneralGraph` representing the
estimated CPDAG.

```python
def run_causal_discovery(X: np.ndarray) -> GeneralGraph:
    """
    Input:  X of shape (n_samples, n_variables), real-valued observations
    Output: estimated CPDAG as causallearn.graph.GeneralGraph.GeneralGraph
    """
```

Valid contributions may use constraint tests, score search, ordering or
permutation search, hybrid criteria, or a new modular CPDAG estimation
strategy, provided the output respects the expected causal-graph
representation.
